# Sistema de Fichas de Treino para Academia

Projeto pessoal para criação de um sistema interno de gerenciamento de fichas de treino de uma academia, com geração de fichas em PDF para impressão, com QR Code para facilitar o acesso do aluno à versão digital e histórico para os profissionais.

## Objetivo

Substituir o processo manual de fichas em papel escritas a mão por um sistema digital simples e organizado, sem alterar drasticamente a rotina da academia.

## Estrutura do projeto

- `/docs` - Documentação do sistema.
- `/backend` - API Spring Boot.
- `/frontend` - Interface web para profissionais e alunos.

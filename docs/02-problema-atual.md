# Problema Atual

Atualmente as fichas de treino são preenchidas manualmente em papel, gerando problemas como:

- Lentidão no preenchimento.
- Possíveis dificuldades de compreender a letra.
- Processo de criação e atualização dos treinos mais trabalhoso.
- Ausência de versão digital, podendo ser incomodo para alunos mais jovens que gostariam de acompanhar o treino pelo celular.
- Dificuldade de acompanhar o histórico de treinos de cada aluno.
- Dificuldade para organizar treinos A, B, C, etc. no mesmo papel.
- O sistema atual não possibilita que o aluno consulte seu treino fora da academia, em cenários como uma viagem por exemplo.

Além disso, o modelo atual depende **totalmente** do papel, o que limita o acompanhamento e a evolução dos alunos ao longo do tempo.

# Escopo

O sistema irá:

- Cadastrar alunos.
- Cadastrar professores.
- Criar e editar fichas de treino.
- Criar treinos A, B, C organizados.
- Selecionar exercícios com cliques.
- Gerar PDF da ficha no layout da academia.
- Gerar QR Code por aluno.
- Manter histórico de fichas.

O sistema NÃO irá:

- Controlar presença.
- Controlar progressão de cargas.
- Substituir completamente o uso de papel.
- Exigir uso de celular pelos professores do salão.

# Objetivos

- Facilitar a criação de fichas de treino.
- Padronizar a organização dos treinos.
- Gerar ficha em formato PDF para impressão.
- Disponibilizar ficha digital para o aluno.
- Gerar QR Code para acesso à ficha ativa.
- Manter histórico de fichas para os profissionais.
- Tornar o uso simples para garantir adesão real ao novo sistema.

# Regras de Negócio

- Cada aluno possui apenas uma ficha ativa.
- O QR Code sempre aponta para a ficha ativa do aluno.
- O aluno só pode visualizar a ficha ativa.
- O professor pode editar a ficha ativa (ajustes rápidos e pontuais).
- O professor pode criar uma nova ficha em contexto de reavaliação.
- Ao criar nova ficha, a antiga se torna inativa.
- Fichas inativas ficam disponíveis no histórico apenas para visualização dos profissionais.
- A ficha gerada em pdf para impressão vem com as cargas em branco, continuando a ser responsabilidade do professor preenche-las manualmente no dia a dia.
- A presença continua sendo controlada manualmente.

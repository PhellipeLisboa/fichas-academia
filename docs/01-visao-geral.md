# Visão Geral

O sistema tem como objetivo substituir o processo manual de criação de fichas de treino da academia por um sistema digital simples, organizado e de fácil uso para os profissionais, mantendo compatibilidade com o uso em papel e oferecendo acesso digital ao aluno.

O foco principal é facilitar a criação, manutenção e registro do histórico das fichas de treino, sem alterar drasticamente a rotina já utilizada pela academia.

O sistema será desenvolvido para uso interno para a academia, mas permitirá acesso público às fichas ativas dos alunos por meio de QR Code.
